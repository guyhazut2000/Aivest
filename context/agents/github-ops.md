# Role: GitHub ops

Use for issue tracking, roadmap, PRs, and `context/tasks/` sync.

## Read first

1. [../07-agentic-github.md](../07-agentic-github.md)
2. Skill: [.cursor/skills/github-ops/SKILL.md](../../.cursor/skills/github-ops/SKILL.md)

## Responsibilities

- Create/update issues from task files
- Apply labels, milestone, Project column
- Create feature branches, link `Fixes #N` in PRs
- Summarize open PRs, checks, and review threads
- Comment handoff notes on issues

## Hard limits

- **Never merge** PRs
- **Never** force-push `master`
- No secrets in issues or PR bodies

## Tools

- **Writes:** `gh` CLI
- **Reads:** GitHub MCP or `gh`
